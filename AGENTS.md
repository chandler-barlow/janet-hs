# Agent instructions

Haskell code in this repository (`lib/`, `exe/`, and any test suites) must
follow [`docs/hs_style_guide.md`](docs/hs_style_guide.md). Read it before
writing or reviewing Haskell in this repo.

This does not apply to the generated bindings under `bindings/Generated/`
(regenerated deterministically by `generate-bindings.sh`, not hand-written
— see `.gitignore`).
